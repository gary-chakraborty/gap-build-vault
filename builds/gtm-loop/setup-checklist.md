# Setup checklist: install order and your first two weeks

Tick each box only when its check passed, not when the account exists.

## Day 1: the free half (Claude only)

- [ ] Claude Project made, business file in Project knowledge, filled with no brackets left
- [ ] Check: a new chat states your offer and buyer correctly
- [ ] Step 1 run. Every fact has a date. Undated facts deleted
- [ ] Step 2 run. Three quotes opened and checked by hand. Top 5 buyer phrases added to the file
- [ ] Step 3 run. One promise, one number, every blank pinned
- [ ] `03b-competitor-ads-prompt.md` run. One offer line changed or kept for a stated reason

## Day 2: research and list tools

- [ ] `secrets/` folder made, files locked (`chmod 600`)
- [ ] Scrapling installed. Check: a blocked page raises an error, not an empty result
- [ ] Serper key. Check: one search returns dated results
- [ ] Apify token. Check: one run on one profile, cost line read before any bigger run
- [ ] Apollo key with people search turned on. Check: one search, one email, one credit used
- [ ] MillionVerifier key. Check: your own address comes back "ok" (browser user agent set)

## Day 3: list and reasons

- [ ] Step 4: 200 companies, each with one dated reason or moved to a watch list
- [ ] Five reasons checked at the source by hand (the date on the page, not the filter)
- [ ] Step 5: one person per company, every address verified, catch-alls on their own list
- [ ] Blank fields checked: no blank size or blank name passed a filter

## Day 4: sending

- [ ] Smartlead key (and the connection, if you want it in Claude)
- [ ] HeyReach key, seats connected
- [ ] One sequence per reason for writing, each with its own list. Two touches, then stop
- [ ] Schedule set **before** start. Status read back as active
- [ ] HeyReach: list total read back and matches your file
- [ ] 5 test people sent. One real sent message read, variables filled, no braces showing

## Day 5: replies and booking

- [ ] Slack bot made, `chat:write`, invited to the channel. Test post landed
- [ ] Reply webhook pointed at your relay. Your own test reply shows as a Slack card
- [ ] Labelling turned off on purpose once. The card still posted, marked unlabelled
- [ ] Calendly token + webhook. A test booking arrived at your receiver
- [ ] Every reminder counted across Calendly and your own emails. No duplicates

## Week 1

- [ ] First real sends. Nothing judged in the first hour
- [ ] Every reply answered by a person within minutes, using the drafted answer as a start
- [ ] Every sales call: brief the morning of (`09`), score the same day (`10`)

## Week 2, Monday

- [ ] Count last week: new people reached, by reason and by channel. Booked from the calendar
- [ ] Any tool that would not load is written as UNKNOWN, not 0
- [ ] `11-weekly-loop-prompt.md` run. One change chosen, with the number that will prove it
- [ ] Business file updated with the change and this week's buyer words
- [ ] Next week's list, offer or reason for writing is different because of it
