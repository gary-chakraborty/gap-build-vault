# The 5-step signal system

This is the method behind checking a lead before you send anything, not after.
Most cold outreach fails because the list is built on a filter (industry, headcount,
job title) instead of a moment. A filter tells you who someone is. A signal tells you
why now. Five steps turn "who" into "who, right now."

## Step 1: Pick the signal

Write one sentence, in this exact shape:

> "A [company type] that [dated public event], because [plain reason this creates the
> need], findable via [where you'll look]."

Example: "A software company that closed a funding round in the last 90 days, because
new investor money brings reporting requirements the founder's old process can't carry,
findable via funding news and public announcements."

Run three checks on that sentence before you move on:
- **Public.** You can point to the exact page, post, or filing where it happened.
- **Dated.** You know when it happened, and it's inside your window (90 days for most
  events, 12 months for a leadership change).
- **Causal.** You can say in one plain sentence why the event creates the need.

Then run the trap check: is this true of every company in the market? "They're growing"
or "they're a mid-size company" is true of everyone and proves nothing. If your sentence
only works because it's vague, it isn't a signal yet.

**How long it takes:** 20-30 minutes, once per segment. You do this once and reuse it for
every list you build against that segment.

**The mistake everyone makes:** picking something true of the whole market and calling it
targeting. "They use HubSpot" or "they're a growing business" isn't a signal, it's a
description. A real signal is something that was NOT true six months ago and is true now.

## Step 2: Build the list around the signal

Don't start from a generic company database and filter down. Start from the source where
the signal itself lives. Use a job board if the signal is a hire, a funding database if
the signal is a raise, a licence board if the signal is a permit or registration. Pull
three to four times your target count, because most hits won't survive Step 3.

**How long it takes:** 1-3 hours for a list of 25-30 companies, depending on the source.

**The mistake everyone makes:** buying a list first and looking for the signal after.
That produces a list that happens to include some companies with the signal, buried in a
pile that doesn't. Go the other way: hunt the signal, then build the list from what you
find.

## Step 3: Verify the signal is real

For every company you plan to keep, open the actual source page. Not the search result,
the page itself. Confirm three things: the event really happened, the date is inside your
window, and you can paste the exact URL next to that row. If you can't find the page in
about three minutes, drop the row. Don't soften the wording to keep it in, delete it.

**How long it takes:** 30-45 minutes for a list of 25-30 companies. This is the highest
value time in the whole process. It's the difference between a list that's real and a
list that looks real.

**The mistake everyone makes:** trusting the tool's raw output without opening the link.
Automated searches return stale results and near-misses constantly. A signal you didn't
personally check is a guess wearing a signal's clothes.

## Step 4: Route one signal to one campaign

Every signal type gets its own list and its own message. Never load two different signal
types into one sending tool as "Variant A" and "Variant B." Most tools rotate variants at
random across the whole list, so a message written for a funding-round signal can land on
a lead whose actual signal was a new hire. That's not personalization, that's a mismatch
with a first name pasted on top.

One signal, one list, one campaign, tagged so you can trace a reply back to the exact
signal that earned it. A true A/B test only ever compares two phrasings of the SAME signal
on the SAME list, never two different signals dressed up as variants.

**How long it takes:** 10-15 minutes of setup discipline per campaign.

**The mistake everyone makes:** treating "we already wrote three angles" as a reason to
merge them into one send. Three angles for three different signals are three campaigns,
not three variants of one.

## Step 5: Run the send-gate check

Before anything goes out, run the checklist in `send-gate-checklist.md`. Five points,
every one has to pass. This is a two-minute check that catches the two most expensive
mistakes: sending a stale signal, and sending the right signal with the wrong first line.

**How long it takes:** 2-5 minutes per campaign.

**The mistake everyone makes:** skipping the check because the list "already went through
verification" in Step 3. Verification confirms the signal was real when you built the
list. The send-gate confirms the message you're about to send actually uses it. Those are
two different checks, and skipping the second one is how a verified signal ships in a
generic-sounding email that never mentions it.
