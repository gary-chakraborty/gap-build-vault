The eight · one line each

What each one actually does.

01

Market Researcher

Finds out who buys this, and what they pay.

How it runs

  1. Check if the problem is growing or dying (Google Trends, last 3 months).
  2. Pull the market size and where buyers are shifting from the consulting firms.
  3. Read what buyers say about the problem where nobody is selling to them.
  4. Check who is hiring for the exact job this replaces.
  5. Write it up. Every fact carries the day it was read.

02

Buyer Psychologist

Finds the words the buyer uses themselves.

How it runs

  1. Find where they actually talk — their subreddits, their forums, their review pages.
  2. Pull the threads and the review bodies, not the star ratings.
  3. Lift the phrases word for word. Never paraphrase them.
  4. Build one persona: what they do all day, what they are scared of, what they want instead.

What it uses

Tools
Serper (finds the threads)Scrapling (reads them)
Where the data comes from
RedditCapterraG2LinkedIn comment threadsindustry forums

This is where “who reconciles the trust account” came from. We did not write that line. It is what small law firms call it, and it is the whole reason the email worked.

03

Offer Writer

Turns it into one promise, for one kind of company.

How it runs

  1. Write one promise: who it is for, what they get, one number.
  2. List every blank the writer will have to fill in.
  3. Pin each blank — exact wording, or a short list of allowed answers.
  4. Write two or three finished examples so nobody has to guess.

What it uses

Tools
No API neededBest model writes it onceCheap model fills it

The test: could two people fill this in two different ways and both be right? If yes, it is not pinned, and it will get invented differently every time.

04

List Builder

Finds real firms. Bins everything else.

How it runs

  1. Write the target down as one saved search — industry, size, country, job titles.
  2. Run it down the sources, cheapest first. Out of credit means skip, not stop.
  3. Dedupe. One row per company, never one per person.
  4. Open each website and read it. This is the step everyone skips.
  5. Drop anything that is not the business you thought it was.

What it uses

The order is: an export you already paid for → the free scraper → a tool that came bundled → prepaid credits → new money, last. The numbers this gate produced are below.

05

Contact Finder

Gets the right person and an email that works.

How it runs

  1. Look for the person on the company's own website first. It is free and it is right.
  2. Not there? Search for them.
  3. Still not there? Try a people-search tool, then a data provider.
  4. Now the email: a lookup that returns a checked address, then an enrichment tool, then guessing the pattern — last.
  5. Verify every address. If it fails, drop the lead.

What it uses

Tools
SerperProspeoApolloMillionVerifier
Where the data comes from
company sitesApollo contact database

Never one provider. One build went single-source and lost 744 firms the others in the chain would have covered.

06

Signal Finder

Works out who is worth emailing this week.

How it runs

  1. Filter for fit first, on the free data you already have — title, headcount, industry, country. Before you spend a credit.
  2. Check the job boards for a role that means they have this problem right now.
  3. Check their site and their DNS — dead blog, which email tool they run, booking software installed.
  4. Go back to the source and confirm it yourself. Do not trust a platform's date filter.
  5. Stamp an expiry date on it. One signal per lead: the freshest and the most specific.

What it uses

Tools

Where the data comes from

No signal, no send. Ever. If you cannot name what changed and put it in line one, that lead goes on a watch list, not into a campaign.

07

Email Writer

Fills in a script that already works.

How it runs

  1. Pick the script that matches the signal. Never write a new one.
  2. Fill the blanks from the lead's own record.
  3. Count the words. Over 64 on the first email means cut, not send.
  4. Load it as its own campaign — never as a variant. Tools rotate variants at random, so one signal's copy would go to the wrong leads.
  5. Set it up as two emails. First, then one follow-up on day two. Then it stops.

What it uses

Tools
Smartlead (sending)the script librarycheap model fills it

No price, no case study, no proof numbers in the first email. Those belong in the follow-up. Both emails are below, ready to copy.

08

Inbox Agent

Answers every reply in five minutes.

How it runs

  1. A reply lands. A webhook fires straight away — nothing waits for someone to check the inbox.
  2. Sort it: green, yellow or red. Interested, unsure, or no.
  3. Pick the matching script. A positive reply and an objection are different scripts.
  4. Fill it in with what that lead actually said.
  5. Send it to the team with the draft already written. A person reads it and presses send.

What it uses

Tools
Smartlead webhookn8nSlackNotion (the scripts)Airtable / Sheets (tracking)

Two specific times, never a calendar link. Never a price, even when pushed. Answering inside five minutes is what tells a prospect this is a real operation.

Setting it up · the short version

Five things. The order matters more than the tools.

1
Get the files

All of it is at github.com/gary-chakraborty/gap-build-vault, folder builds/outbound-agent-stack. No sign-up.

2
What you need

A free scraper, a search key, one contact tool you already pay for, an email verifier, a sending tool. If you run outbound you probably have four of the five.

3
Run them in order

One to eight. Do not skip to the email. The research is what produced the subject line, and you cannot work backwards to it.

4
Start small

One kind of company. One signal. Two hundred leads, not five thousand. A bad list at five thousand costs you your sending domain.

5
Measure by signal, not blended

A blended reply rate hides the one lane that works and the three that do not.

The full install — keys, permissions, every setting — is its own video. Doing it properly takes longer than a section.
