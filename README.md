# The GAP Build Vault

Free, complete AI and automation builds for B2B client acquisition. No email wall. No teaser PDFs. The full thing: prompts, scripts, workflow files, and install steps written so you can run each build today.

## How this works

Every build lives in its own folder under [`builds/`](builds/). Each one has:

- A README that explains what it does, the problem it kills, and every install step
- The prompt files, scripts, and workflow JSONs you need
- A walkthrough of your first run

Browse the cards on the site, or dig through the folders right here.

## Who makes this

These are working systems from [GAP](https://www.linkedin.com/in/garychakraborty), where we build outbound client-acquisition engines for B2B service businesses. The builds here are real pieces of that work, packaged so they run on their own.

If you use one, tell us how it went — every build page has a two-minute feedback form at the bottom. The best stories shape the next build.
